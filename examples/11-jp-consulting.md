# 現状分析：コスト構造
> 配送費の4割を占める「積載ロス」と「再配達」が最大の改善余地
@1:1
```stacked-bar {title="配送コストの内訳（億円）" labels=on}
,2024,2025,2026
幹線輸送,38,40,43
ラストワンマイル,31,34,37
再配達,9,11,13
倉庫作業,22,23,24
```
## 主要な論点
- **積載ロス**：平均積載率68%、帰り便の空車率41%
- **再配達**：再配達率14%、1件あたり 420円のコスト増
- **倉庫作業**：ピッキング動線が長く、1人時あたり 92行
- 3つの論点で配送費の ==41%== を説明できる
> [!note] 2026年度は燃料費高騰（+6%）の影響を含む
※ 出所：管理会計データ（2024–2026年度）
