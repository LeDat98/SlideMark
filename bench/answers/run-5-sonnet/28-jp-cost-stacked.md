# 製造原価の推移
> 原価は4年で11億円増加、材料費が主因
```stacked-column {title="製造原価（億円）" labels=on legend=bottom}
,2023,2024,2025,2026
材料費,40,42,45,47
労務費,22,23,23,24
経費,12,12,13,15
```
## 前年差の要因
- 材料費: 原材料価格の上昇（+2億円）
- 労務費: 賃上げ（+1億円）
- 経費: 物流・光熱費の増加（+2億円）
@end

| 項目 | 2026年度 | 前年差 |
|---|---|---|
| 材料費 | 47億円 | +2億円 |
| 労務費 | 24億円 | +1億円 |
| 経費 | 15億円 | +2億円 |
| 合計 | 86億円 | +5億円 |

※ 前年差は2025年度比。単位: 億円
※ 出所: 社内原価管理システム（2026年度）
