# Công thức lãi suất kép
> Lãi sinh lãi: số tiền tăng theo hàm mũ
```math
A = P\left(1 + \frac{r}{n}\right)^{nt}
```
## Ký hiệu
- A: tổng số tiền sau t năm
- P: vốn gốc
- r: lãi suất năm
- n: số kỳ ghép lãi mỗi năm
- t: số năm
## Ví dụ
P = 100 triệu, r = 6%/năm, n = 12, t = 3
```math
A = 100\left(1 + \frac{0{,}06}{12}\right)^{36} \approx 119{,}67 \text{ triệu}
```
