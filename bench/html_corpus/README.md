# HTML fidelity corpus (DF4)

Agent-designed slides written as HTML/CSS, one `<section>` per file, 1280×720 px (13.333 × 7.5 in).
Used by `bench/html_fidelity.py` (DF4): share of visible elements that become native editable shapes, and
the perceptual diff between the Chromium render and the .pptx render. Files are data: never auto-format.
